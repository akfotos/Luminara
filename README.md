# Luminara

A faith-driven creative community website — clean, modern, and Pixieset-inspired.

## Design

- **Color Palette**: Deep forest green (#1A4731), sage, soft greens, warm cream, off-white
- **Typography**: DM Sans + DM Serif Display (via Google Fonts)
- **Style**: Minimal, editorial, generous whitespace, grid-based layout

## Features

- Split hero with featured creator card
- Category cards with SVG icons and green flip hover effect
- Featured works grid with tonal color blocks
- Stats panel with animated counters
- Testimonials section
- Responsive design (mobile, tablet, desktop)
- Smooth scroll and fade-in animations
- Dark footer

## Tech Stack

Plain HTML, CSS, and JavaScript — no frameworks, no build tools.

## Getting Started

Open `index.html` in any browser, or serve it locally:

```bash
npx serve .
```
